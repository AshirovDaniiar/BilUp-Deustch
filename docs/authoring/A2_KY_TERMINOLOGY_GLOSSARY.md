# A2 — Kyrgyz terminology glossary (working document, started in Stage 7C with Unit 12)

**Status of every entry: AI-assisted draft — NOT reviewed by a native Kyrgyz speaker.** The purpose of this file is to *record* terminology decisions and doubts, so that no disputed term is silently invented or standardised across the nine remaining units. A native reviewer fills the last column; only then does a term become binding.

**Policy used in Unit 12**

1. A term that is **not** settled is **not used as a label**. The text *describes* the idea in plain Kyrgyz or keeps the German word in Latin script (as Unit 11 does for *Perfekt, Partizip II, Dativ*).
2. The terms still open from Unit 11 (K4, K7, K8, K9, K12, K13, K14, K16, K18 — see `A2_UNIT11_KY_QA.md`) are **not reused** in Unit 12: no *жөндөлгөн/жакталган этиш*, no *ээрчимелүү/багыныңкы сүйлөм*, no *ажыраган/бөлүнүүчү приставка*. (Two glosses in Unit 12 first used *ажыраган приставка*; they were rewritten descriptively before release of the draft.)
3. Kinship words are given as **descriptions**, never as an invented single term.
4. German and Russian examples inside Kyrgyz explanations stay unchanged (validated by tests).

## 4. Address forms (carried over from Unit 11, still open — K18)

German *du* → Kyrgyz *сен*, *Sie* → *сиз* in dialogues; instructions use polite *-ңыз*. Unit 12 follows the German register of each text (all Unit 12 dialogues are informal, *du*), so Kyrgyz uses *сен* / *-ң* forms in dialogues and polite *-ңыз* in instructions.

## 5. How to use this glossary

* Authors **add** a row whenever a new term family appears (Unit 13: adjective endings, comparison, position verbs; Unit 14: imperative, modal verbs, `wenn`; …) and mark it *draft*.
* A native reviewer decides each doubtful row; the decision is then applied to **all** units in one pass.
* Nothing in this file is approved. No reviewer is named or implied.

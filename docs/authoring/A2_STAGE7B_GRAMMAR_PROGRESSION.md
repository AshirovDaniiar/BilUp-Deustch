# A2 Stage 7B — Grammar progression, Units 11–20

**Status:** curriculum DESIGN. Nothing here is production content; nothing is approved. Every "A2 suitability" statement is the author's assessment from common curriculum practice — **not** a CEFR authority and **not** a human review. Unit 11 is the authored pilot and is described only as the starting point; it is unchanged.

## 1. Principles

1. **One new idea per concept, introduced when a task needs it.** A structure is taught in the first unit whose target task cannot be done without it, and recycled (never re-taught) afterwards.
2. **Productive vs. receptive grammar.** A structure may appear *receptively* in a text before it is taught (a chunk the learner only understands); it is *required* in tasks only from the unit that teaches it.
3. **A2 ceiling.** Subordination is limited to `weil`, `dass` (after glauben/wissen/finden), `wenn`, `als` (unit 17, pending decision), indirect questions with `ob`/W-word (unit 19, pending decision). No Passiv, Relativsatz, Konjunktiv II as a taught form, Plusquamperfekt, `um … zu`, `obwohl`, `damit`, `nachdem`, Genitiv production.
4. **Spiral assessment.** Each final test recycles earlier structures in at least two items (marked ↻ in the curriculum design).
5. **Concept ids** follow the authoring guide (`a2-<kebab-case>`), are permanent and unit-owned.

## 2. Unit 11 — the starting point (authored, unchanged)

| Concept | What the learner can do afterwards |
| --- | --- |
| `a2-perfekt-erfahrungen` | Perfekt with haben/sein, *ge-less* participles, separable verbs, `vor` / `seit` / `schon einmal` / `noch nie`; reflexive verbs only as chunks (*habe mich entschieden*) |
| `a2-praeteritum-sein-haben-modal` | war / hatte / konnte / wollte / musste |
| `a2-ereignisse-verbinden` | zuerst … schließlich (verb in position 2), `weil` (revision from A1; verb-final incl. Perfekt auxiliary), `dass` after glauben / wissen / finden |

## 8. Structures deliberately excluded from A2

Passiv · Relativsatz · Konjunktiv II as a taught form · Plusquamperfekt · Futur II · `obwohl`, `damit`, `nachdem`, `sobald`, `trotzdem` · `um … zu` and `zu` + infinitive · Genitiv (production) · reflexive Dativ as a rule · pronominal adverbs as a rule (*darauf, womit*) · Partizip as adjective · lassen-constructions.

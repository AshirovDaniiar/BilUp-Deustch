# Architecture Changelog

## Revision 3 — subscription model integration and final architecture review (5 November 2026)

**Trigger:** the newly approved business model — two monthly plans in KGS (**BilUp Basic 99 KGS**, **BilUp Premium Live 149 KGS** = Basic + weekly German and English **BilUp Live**), the **no-recording** rule, and the request for a final consistency review. Documents were **edited in place**; historical decisions that changed are listed in §3.R3 below. No application source, `package.json`, dependency, migration or infrastructure was changed.

## 2. Corrections to my own earlier statements
Three statements in revision 1 were wrong and are corrected: (a) the Kyrgyz "Russian-only letters" denylist (C-1); (b) "expired holds are filtered by a DB query" — an exclusion constraint cannot reference `now()`, so expiry must be a state transition plus lazy expiry in the booking transaction; (c) "authorize at booking, capture at confirmation" as the payment default, which does not work for far-future lessons.

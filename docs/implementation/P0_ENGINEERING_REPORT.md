### Known gaps / defects discovered (pinned by tests, **not fixed**, per "no functional change")
1. **XP is not idempotent** (03 §4, V-04/V-05) — repeating an activity repeats the reward.
2. **A corrupt stored value is overwritten on first load** (the persist effect writes defaults immediately) — no backup, truncated data is destroyed. Highest risk for P1.
3. **No validation of stored data:** wrongly typed fields are accepted; a non-array `activeDates` makes the first progress action **throw** (crash path); a string `xp` concatenates (`"100"+5 → "1005"`); a JSON array leaks index keys into state.
4. **Silent Russian fallback** for Kyrgyz/German in both UI strings and content (`tr`, `makeT`), contrary to 02 §5; 173/280 Kyrgyz UI strings are identical to Russian; 272/352 grammar/exercise L10n strings have no Kyrgyz text.
5. **SRS quirk:** a *wrong* first answer moves a word to box 1, like a correct one.
6. **Badge quirk:** "streak3" is awarded for any 3 active dates, not consecutive ones.
7. **5 boundary violations:** `features/{listening,reading,reallife,speaking,writing}/*` import `screens/NotFound`.
8. **8 pre-existing a11y warnings** (jsx-a11y): `components/ui.tsx` 120–121 (click handlers on non-interactive elements, no keyboard handler), `features/writing/WritingLab.tsx` 60–61 and `screens/ProfileScreen.tsx` 16, 18 (form controls without associated labels).
9. The roadmap's note about "any-score unit-test completion" (`PracticeScreens.tsx:118` completes the unit test regardless of score) is a **screen-level behaviour that is not tested** — no screen is rendered by any test.
